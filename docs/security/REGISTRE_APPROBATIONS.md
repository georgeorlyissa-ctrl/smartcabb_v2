## Règles

1. Un document « Projet » ne peut pas être présenté comme une procédure
   obligatoire avant approbation.
2. L'approbation se fait par signature (PDF ou registre) par la direction.
3. Toute nouvelle version remplace l'ancienne ; l'historique est conservé.
4. Les documents approuvés sont archivés hors dépôt (PDF signé).
5. Une revue annuelle est planifiée ; un incident majeur peut déclencher une
   revue immédiate.
